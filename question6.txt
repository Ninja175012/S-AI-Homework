Simplify the Compilation Process

#!/bin/bash
cat > hello.c << 'EOF'
int main(void) {
    printf("Hello from C\n");
    return 0;
}
EOF
cat > build.sh << 'EOF'
#!/bin/bash
gcc hello.c -o hello
EOF
chmod +x build.sh
./build.sh
./hello

Use cat to enter text into c compiler and function needed to print Hello from C chmod for giving execution permission and ./hello to execute it
